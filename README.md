# vocab-test

주니어 능률 VOCA STARTER 2 (DAY 01~40, 480단어) 온라인 단어 시험.

- 단일 파일: `index.html` (빌드 없음)
- 기능: DAY 범위 선택, 문제 수, 제한 시간 타이머, 뜻 쓰기·철자 쓰기 섞기 (객관식 없음), 결과·오답 재시험
- 단어 출처: classcard 폴더 362380 (netutor 선생님 세트), DAY별 기본 세트 40개

## 선생님 기능
- `teacher.html`: 반 만들기(반 이름 + 비밀번호) → 6자리 반 코드와 학생용 링크(`/?c=코드`) 발급
- 학생이 반 코드로 시험 보면 결과 자동 전송 (오프라인이면 대기 후 자동 재전송)
- 선생님 화면: 학생별 평균, 자주 틀린 단어, 시험별 상세, CSV 저장, 결과 지우기(숨김)
- 저장소: Supabase(DALMA DEV 프로젝트 안 `vocab_` 테이블). 테이블 직접 접근 차단, `vocab_*` RPC로만 접근. 비밀번호는 bcrypt 해시, 10회 실패 시 10분 잠금
